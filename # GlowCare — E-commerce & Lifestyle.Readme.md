# GlowCare — E-commerce & Lifestyle Landing Page

## Project Overview
GlowCare is a fictional skincare and lifestyle brand focused on everyday self-care. This project is a responsive landing page concept designed in Figma to showcase skincare products and provide a clean, user-friendly shopping experience.

## Target Audience
- Skincare and beauty enthusiasts
- Young adults aged 18–35
- Customers interested in self-care and skincare products

## Design Goals
- Create a clean, modern, and premium visual identity.
- Make products and shopping actions easy to discover.
- Maintain consistent spacing, typography, and colors.
- Adapt the layout for desktop, tablet, and mobile screens.

## Design System

### Color Palette
- Sage Green: `#84977A`
- Cream: `#F8F5EF`
- Warm Beige: `#E7DCCB`
- Dark Charcoal: `#292B27`

### Typography
- Headings: Playfair Display
- Body Text: Inter

### Visual Style
Minimal, elegant, and nature-inspired, with generous whitespace, rounded corners, and skincare product photography.

## Page Sections

1. **Header:** Brand logo, navigation links, and shopping bag.
2. **Hero Section:** Main headline, supporting text, product image, and call-to-action buttons.
3. **Shop by Category:** Face Care, Body Care, and Self-Care cards.
4. **Best Sellers:** Product cards with images, names, prices, ratings, and Add to Cart buttons.
5. **Brand Story:** Introduction to GlowCare and its approach to self-care.
6. **Promotion Banner:** Featured message and shopping call-to-action.
7. **Testimonials:** Customer review cards.
8. **Newsletter:** Email subscription form.
9. **Footer:** Useful links, social media icons, and copyright information.

## Reusable Figma Components
- Header / Navigation
- Primary and Secondary Buttons
- Product Card
- Category Card
- Testimonial Card
- Newsletter Input
- Footer Link

Components should be reused consistently throughout the page. Use component variants for button states where appropriate.

## Responsive Layouts
The design supports the following frame widths:

- Desktop: 1440 px
- Tablet: 768 px
- Mobile: 390 px

The layout adapts to smaller screens by stacking content, adjusting grids and spacing, keeping text readable, and ensuring buttons and inputs are easy to tap.

Use Figma Auto Layout and responsive resizing settings, and check that no horizontal overflow occurs.

## Figma Techniques
- Auto Layout for headers, buttons, cards, and content sections
- Reusable components and variants
- Shared color and typography styles
- Consistent spacing based on an 8-point system
- Clear layer, frame, and component naming

## Tools Used
- Figma
- Figma Auto Layout
- Figma Components

## Note
GlowCare is a fictional concept created for a UI/UX design assignment. Product names, prices, testimonials, and brand details are illustrative and should not be treated as real offers or customer reviews.
